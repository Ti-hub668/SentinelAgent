# Frontend Design System v1

SentinelAgent 保持现有蓝灰安全运营控制台、导航与业务结构。本规范统一呈现层；不改变扫描、调查、审批、执行与审计行为。

## 样式归属

- frontend/src/styles/design-system.css：唯一的通用视觉规范，负责 tokens、页面 Header、卡片、统计、表格、表单、长文本与通用内容间距。
- global.css：基础样式及既有布局基础。
- 各页面 scoped CSS：页面特有的 Grid 拓扑、交互状态和响应式降栏；避免重新声明通用 Header / summary card 的字体和内边距。
- 设计系统通过 app-shell / page-content 显式限定作用域，避免路由按需加载的旧 scoped 样式覆盖通用规范。细化内容区内边距时，卡片与卡片 Header 只保留一层有效内边距。

## 统一规则

| 项目 | 规则 |
| --- | --- |
| 色彩 | 蓝灰正文 #233248、次级文字 #64748b、强调色 #078fb9、白色卡片 |
| 页面 | 宽屏 padding 28px 32px 40px；1440 以下侧边距 24px；900 以下 20px；640 以下 16px |
| Header | 标题 26px / 1.3；描述 14px / 1.7；标题与描述间 8px；下一块间 24px |
| 内容节奏 | 页面 section gap 24px；Grid gap 20px；控件组 gap 12px |
| 卡片 | padding 20px 24px；圆角 12px；min-width: 0；高度自适应 |
| 统计 | 最小高度 136px；数字 30px；文本型结论 17px，自然换行 |
| 表格 | 字号 13px；单元格上下 padding 13px；仅表格内部可横向滚动 |
| 表单 / 按钮 | label 与输入间 8px；按钮最小高度 36px，内容可换行 |
| Tag | 轻量色彩，自适应高度；容器与内容均可换行 |
| 安全文本 | 标题、摘要、metadata 不用省略号隐藏；JSON 保留原文并局部滚动或换行 |

图表画布保留渲染所需尺寸，外部卡片自动扩展。时间线和运行队列保留有意设计的局部滚动区域，避免整个页面无限增长。

Audit 保留宽屏三栏、≤1600 两主栏且 detail 下一行、≤1180 单栏。Findings 保留主从布局与 metadata 的 4 → 2 → 1 列。不能为规避溢出而缩小字体。

## 文案与真实状态

固定 UI 文案全部经 vue-i18n；中文使用中文业务术语，英文不混入中文（语言选择器的语言自称除外）。技术名称保留原文。Nuclei 标题、证据、LLM 分析、威胁情报和原始审计 JSON 不自动翻译。

Settings 只修改浏览器语言偏好；刷新调用现有 GET /health。该接口仅返回应用健康标识，因此只能显示后端接口检查与时间。MySQL、Ollama、模型名称、扫描器、模板、GitHub 及全局执行开关没有状态 API，展示明确的配置说明与未提供状态提示。不得显示虚假在线或启用状态。

身份登录、资料、邮箱验证、密码、2FA 和 RBAC 控件需先有真实后端能力，当前保留为未来工作，不在演示 UI 放置无效按钮。

## 验证基线

检查九个主要页面 × 中文/英文 × 1920/1600/1440/1280。重点覆盖有真实数据的调查、响应、审计与 Finding 详情，而不只检查初始空页面。每次修改通用规范后运行 npm run build、Vue 模板/翻译检查和 git diff --check。
